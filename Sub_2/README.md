# This is the readme file for submission "Sub_2"

## dataset folder

This folder contains all the datasets required for training and testing the model.
The file "train_DPC.csv.zip" contains the tain_DPC.csv file used to train the model. So unzip it after downloading the zip file.

##### IMPORTANT: KEEP ALL THE FILES IN THE SAME DIRECTORY FOR EASY ACCESS.

## Environment Folder:

This folder contains environments for both the windows and linux environmnet. Use the Env_installer_README.md file to cleanly install the environments.

## Codes Folder:

This folder contains all the codes used to:
  1) Select features
  2) Select the best model
  3) Train the best model
  4) Validate the best model
  5) Give predictions on the test set
