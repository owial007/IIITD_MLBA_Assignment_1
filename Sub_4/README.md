# This is the readme file for submission "Sub_4"

## dataset folder

This folder contains all the datasets required for training and testing the model.
The file `.npy` files are the main files used to train and test the model. Please keep all the files in the same directory if running on default settings.

##### IMPORTANT: KEEP ALL THE FILES IN THE SAME DIRECTORY FOR EASY ACCESS.

## Codes Folder:

This folder contains all the codes used to:
  1) Select features
  2) Select the best model
  3) Train the best model
  4) Validate the best model
  5) Give predictions on the test set
